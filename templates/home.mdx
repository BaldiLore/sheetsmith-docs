## How it works

<ol class="steps-home not-content">
	<li>
		<strong>Add the starter.</strong> One dependency. The auto-configuration registers a ready-to-use <code>Sheetsmith</code> bean; without Spring, use the builder.
	</li>
	<li>
		<strong>Annotate a class.</strong> <code>@ExcelSheet</code> on the class, <code>@ExcelColumn</code> on the fields to export. Records and inherited fields work too.
	</li>
	<li>
		<strong>Call <code>generate</code>.</strong> Pass the rows, get a <code>byte[]</code> or write straight to an <code>OutputStream</code>.
	</li>
</ol>

## Three presets, one accent colour

Every table style is derived from a single colour, so a report matches your brand with one attribute. Declared styles override a preset attribute by attribute.

## Errors you can act on

Configuration mistakes are caught before anything is written, all at once, each with a stable code that points to its explanation.

```text
[V-06] com.example.report.CustomerRow.revenue: style "money" is not defined
```
